
# События GA4 - Квадрат Ремонт

| Событие | Назначение | Статус |
|---|---|---|
| page_view | Просмотр страницы | Проверено в GA4 Realtime |
| scroll | Прокрутка страницы | Проверено в GA4 Realtime |
| click | Переход по внешней ссылке | Настроено |
| file_download | Скачивание файла | Не реализовано |
| form_start | Начало заполнения формы | Проверено в GA4 Realtime |
| form_submit | Отправка формы | Проверено в GA4 Realtime |
| generate_lead | Отправка заявки | Проверено: заявка записана в Google Sheets, событие зафиксировано в GA4 |
| cta_click | Нажатие на CTA-кнопку | Проверено в GA4 Realtime |
| repair_type_select | Выбор типа ремонта | Проверено в GA4 Realtime |
| repair_calc | Расчёт стоимости ремонта | Проверено в GA4 Realtime |
| portfolio_filter | Фильтрация портфолио | Не реализовано: фильтры отсутствуют |
| project_view | Просмотр отдельного проекта | Не реализовано: отдельных страниц проектов нет |
| stage_open | Раскрытие этапа ремонта по нажатию | Проверено в GA4 Realtime; используется параметр stage_name |
| promo_copy | Копирование промокода | Не реализовано: кнопка копирования отсутствует |
| contact_click | Нажатие на телефон или почту | Не реализовано: контактные ссылки требуют настройки |
| messenger_click | Нажатие на мессенджер | Не реализовано: ссылки требуют настройки |
| social_click | Нажатие на социальную сеть | Не реализовано |
| form_error | Ошибка отправки формы | Настроено, требуется отдельная проверка |
| video_play | Воспроизведение видео | Не реализовано: видео на сайте отсутствует |
| gallery_view | Открытие изображения галереи | Проверено: 6 событий в GA4 Realtime; используется AI-иллюстрация |

## Примечания

- Проверка событий выполнялась через отчёт GA4 Realtime.
- `generate_lead` проверено: тестовая заявка записывается в Google Sheets, событие фиксируется в GA4.
- Для `stage_open` в техническом задании предусмотрен параметр `stage_id`, в текущей реализации используется `stage_name`.
- `gallery_view` срабатывает при открытии изображения `portfolio-gallery.png`. Изображение является AI-иллюстрацией, а не фотографией реального объекта.
- `video_play` не реализовано, поскольку видео на сайте отсутствует.
- Статусы «Настроено» не означают, что событие прошло отдельную проверку в GA4.
