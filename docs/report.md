
# Отчёт о тестировании - Квадрат Ремонт

Проверена работа основных страниц сайта:
- Главная страница.
- Услуги.
- Калькулятор ремонта.
- Портфолио.
- Этапы ремонта.
- Чек-лист.
- Контакты.
- Страница благодарности.
- Политика конфиденциальности.
- Страница 404.

## 2. Проверка калькулятора

Проверен контрольный пример:
- Тип ремонта: капитальный.
- Площадь: 40 м².
- Демонтаж: включён.
- Санузел: не включён.
- Стоимость работ: 388 000 ₽.
- Срок выполнения: 48 дней.
- Материалы: 135 800 ₽.

Результат соответствует контрольному примеру из технического задания.

## 3. Проверка GA4

Проверена отправка событий Google Analytics 4.

Успешно проверены:
- page_view
- scroll
- form_start
- form_submit
- generate_lead
- cta_click
- repair_type_select
- repair_calc
- stage_open
- gallery_view

Дополнительная проверка:
- gallery_view - событие зафиксировано в GA4 Realtime.
- stage_open - после нажатия на четыре этапа зафиксировано четыре события.

Другие события и их статусы указаны в файле docs/events.md.

## 4. Проверка формы заявок

Настроена отправка данных формы в Google Sheets через Google Apps Script.

Проверена запись тестовых заявок в таблицу Kvadrat - Leads.

## 5. Результат

Основные функции сайта реализованы и проверены. Настроены калькулятор ремонта, форма заявок, передача данных в Google Sheets и аналитика GA4.

Некоторые события GA4 оставлены нереализованными из-за отсутствия соответствующих элементов на сайте. Подробности приведены в docs/events.md.
