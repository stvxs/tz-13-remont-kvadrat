Политика конфиденциальности

1. Общие положения

Настоящий документ описывает общие принципы обработки информации, получаемой через сайт ООО «Квадрат Ремонт».


2. Получаемая информация

При отправке заявки пользователь может предоставить имя, контактные данные и сведения о планируемом ремонте.


3. Цели обработки

Информация используется для обработки обращений, связи с пользователями и подготовки предварительных расчётов.


4. Защита информации

Компания принимает меры для защиты полученной информации от неправомерного доступа.


5. Контакты

Контактные данные для обращений будут указаны после согласования с заказчиком.
